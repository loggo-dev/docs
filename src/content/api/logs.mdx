## `GET /api/workspaces/:workspaceId/logs`

<Badge text="GET" variant="info" size="medium" /> <Badge text="Workspace Member" variant="default" size="medium" />

Fetches a paginated list of logs for a workspace.

**Query Parameters**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `day` | string | No | Filter by a specific day (YYYY-MM-DD) |
| `from` | string | No | Filter logs created after this date |
| `to` | string | No | Filter logs created before this date |
| `tag` | string | No | Filter by tag name |
| `page` | string | No | Page number for pagination |

**Response**

```json
{
  "logs": [
    { "id": "01HXYZ...", "day": "2026-09-06", "title": "Meeting notes", "body": "...", "createdAt": "...", "updatedAt": "..." }
  ],
  "hasMore": false,
  "page": 1,
  "limit": 50
}
```

## `POST /api/workspaces/:workspaceId/logs`

<Badge text="POST" variant="success" size="medium" /> <Badge text="Workspace Member" variant="default" size="medium" />

Creates a new log on a specific day.

**Request body**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `day` | string | Yes | The date to attach the log to (YYYY-MM-DD) |
| `body` | string | Yes | Markdown content of the log |
| `title` | string | No | Optional title |
| `posX` | number | No | Canvas X coordinate |
| `posY` | number | No | Canvas Y coordinate |
| `width` | number | No | Canvas width |
| `height` | number | No | Canvas height |
| `zIndex` | number | No | Canvas Z-index |

**Response:** `200` with `{ "log": LogSummary }`
